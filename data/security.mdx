## Protections in place

| Layer | Measure |
|---|---|
| **Data in transit** | All traffic is encrypted over TLS/HTTPS |
| **Data at rest** | Database encrypted at rest using AES-256, provided by AWS |
| **Integration tokens** | Access tokens for connected banks/brokers (Plaid, Zerodha) are additionally encrypted at rest with AES-256-GCM before storage |
| **Device storage** | Authentication tokens stored in iOS Keychain / Android Keystore via Expo Secure Store |
| **App lock** | Optional biometric app lock (Face ID / fingerprint), verified on-device by your operating system |
| **API authentication** | All requests require a signed JSON Web Token (JWT) |
| **Access control** | Collaborative spaces enforce granular role-based permissions |
| **Input validation** | All API requests are validated using Protocol Buffer schema validation (protovalidate) |
| **Internal access** | Access to user data is restricted to authorised personnel on a strict need-to-know basis |

For our full security programme, see the [Information Security Policy](/legal/security) and the [Access Controls Policy](/legal/access).

## Connected accounts

Connected-account integrations (Plaid, Zerodha) are currently in **limited preview**. When available and you connect a bank (via Plaid) or your Zerodha account, we **never** receive your login credentials — authentication happens directly with the provider. We store only an access token, encrypted with AES-256-GCM, which you can revoke at any time by disconnecting. See [What we store](/data/storing).

## What we do not do

- We do not store passwords in plaintext — passwords are one-way hashed
- We do not receive or store your bank or brokerage login credentials
- We do not have access to your authentication tokens after they are issued to your device
- We do not receive your biometric data — the app lock is handled entirely by your device
- We do not use any client-side monitoring that could expose your financial data to third parties

## Limitations

No system is perfectly secure. Transmission over the internet carries inherent risk. If you discover or suspect a security issue, contact us immediately at [support@recontrol.money](mailto:support@recontrol.money).

## Data breach notification

In the event of a personal data breach, we will notify the **Data Protection Board of India** and affected users in line with the timelines set out in the **Digital Personal Data Protection Act, 2023** and the **Digital Personal Data Protection Rules, 2025**, and applicable requirements under the **Information Technology Act, 2000**. Our incident-response process is described in the [Information Security Policy](/legal/security).

## Storage location

Your data is stored in **AWS ap-south-1 (Mumbai, India)**. There is no secondary copy or offsite backup in another region.

If you use Recontrol from **outside India** (including the US or Canada), your data is transferred to and stored in India; while there it is subject to Indian law. See the [Privacy Policy](/legal/privacy#8-data-storage-location-and-international-data-transfers) for the cross-border disclosure and your regional rights.

If you connect a bank using **Plaid**, your banking data is processed by Plaid in the **United States** before reaching us in India — this only happens if you choose to use the bank-connection feature.
